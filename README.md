# garageManagementSystem

Java console “Premium Vehicle Repository”: add, view, edit, and delete Aircraft and Rocket records, then save/load them from timestamped text files.

## Stack
- Java
- Console I/O (`garage2/src`)

## Run
```bash
cd garage2/src
javac *.java
java Garage
```
